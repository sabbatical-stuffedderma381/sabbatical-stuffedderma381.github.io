# Tanvir Portfolio

A lightweight professional portfolio built for GitHub Pages.

## Publish to GitHub Pages

1. Open your `tanvir9982000.github.io` repository.
2. Upload everything inside this folder to the root of the repository.
3. Commit the files to the `main` branch.
4. Wait about 1–3 minutes.
5. Visit `https://tanvir9982000.github.io`.

## Files

- `index.html` — website content
- `styles.css` — light-theme design and responsive layout
- `script.js` — mobile navigation and reveal animations
- `assets/profile.jpg` — profile photo
- `assets/Mohammad_Tanvir_Rahman_Resume.pdf` — downloadable résumé

## Customize

Edit `index.html` to change wording, links, or project content. No build step is required.
